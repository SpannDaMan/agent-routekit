# Changelog

All notable changes to this project are documented here.

## 0.1.1 — Policy-Bound Route Receipt

- Added explicit assumptions, unresolved evidence, eligible alternatives, tool identity, and the no-execution boundary.
- Added strict independent outcome attachments and deterministic non-causal reconciliation receipts.
- Added a 30-case activation suite and fail-closed one-case host-independent publication evidence gate.
- Preserved local provider-neutral planning with no runtime dispatch, live benchmarking, or fabricated outcomes.

## 0.1.0 — local publication hardening

- Added deterministic quality-, complexity-, risk-, and capability-aware route selection.
- Added fail-closed complete executor/verifier-plan selection for high-risk work, including deterministic fallback when a cheaper executor has no independent verifier.
- Added JSON and text routing receipts with fingerprints and rejected alternatives.
- Added strict registry and task validation with public JSON Schemas.
- Added a Codex plugin manifest, repo marketplace, orchestration skill, examples, and plugin-page media.
- Added an installable `agent-routekit` Python console command with no runtime dependencies.
- Added cross-platform CI, single-pass path-redacted release validation, negative-path regression coverage, security and provenance controls, and a 30-day maintainer pilot.
- Added public privacy, terms, funding, OpenAI/Codex, Claude Code, release-evidence, and evaluation package surfaces.
- Replaced opaque plugin art with the accepted transparent master and regenerated the public asset family.
