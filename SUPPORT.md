# Support

During the 30-day maintainer pilot, support is best-effort and focused on installation, registry validation, routing correctness, receipt determinism, and documentation defects.

After publication:

- use a GitHub bug report for reproducible defects;
- use a feature request for a bounded product need;
- use private vulnerability reporting for security issues;
- remove secrets and private task content before sharing any fixture or receipt.

The maintainer target is an initial response within five business days during the pilot. This is a target, not a service-level agreement.
